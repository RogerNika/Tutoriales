Herramientas de depuración

  • DevTools: Network, Console, Performance, Lighthouse.
  • Android Studio Profiler: CPU, memoria, red en dispositivos reales [web:38].
  • Xcode Instruments: Análisis de rendimiento iOS.
  • Registros: error, warn, info, debug.
  • Monitoreo: Sentry/Crashlytics.

Cómo se utilizan los registros del sistema para identificar defectos

  • console.error(): Errores críticos que detienen ejecución.
  • console.warn(): Advertencias de problemas potenciales.
  • console.log(): Estados normales y valores de variables.
  • console.debug(): Información detallada en desarrollo.
  • Filtrado: Buscar por nivel/texto en DevTools para aislar defectos [web:32].

Proceso de refactorización de código

  • 1. Identificar: Detectar código duplicado, funciones largas (>50 líneas).
  • 2. Extraer: Crear funciones reutilizables y constantes.
  • 3. Simplificar: Eliminar condicionales anidados, usar early returns.
  • 4. Probar: Ejecutar tests automatizados antes/después.
  • 5. Revisar: Pull Request con métricas de calidad [web:34].

Mecanismos de seguridad en Apps

  • Permisos: Solicitar solo necesarios (location, camera), revocables dinámicamente.
  • Archivos de configuración: .env con variables sensibles, nunca en código fuente.
  • Cifrado: WebCrypto API para datos sensibles en cliente.
  • Autenticación externa: Firebase Auth, OAuth2 con PKCE.

Seguridad

  • Protección de datos: HTTPS, minimizar datos sensibles.
  • Autenticación: OAuth2/JWT, renovación, revocación.
  • Mitigación: Validación de entradas, CSP, limitar permisos.
  • Cifrado: WebCrypto para hashing/cifrado.
