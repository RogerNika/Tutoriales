Tipos de empaquetado en App

  • Android Package (APK/AAB)
  • iOS App Bundle
  • Progressive Web Apps (PWA)
  • Capacitor App Packaging
  • Cordova App Packaging

Herramientas y procedimientos de empaquetado de App

  • Capacitor - Empaquetado y puente nativo para apps híbridas.
  • Apache Cordova - Herramienta clásica para empaquetado de apps móviles híbridas.
  • Android Studio Build System - Procedimientos para empaquetado Android.
  • Xcode - Procedimientos de empaquetado y firma para iOS.

Cómo diferenciar las herramientas y procedimientos de empaquetado

  • Capacitor y Cordova: Orientados a apps híbridas con webviews; Capacitor es más moderno y mantiene integración nativa.
  • Android Studio y Xcode: Usados para empaquetado nativo y publicación en sus respectivas tiendas.
  • PWAs: Empaquetado basado en certificación web (manifest.json y service workers) sin pasar por tiendas.

Herramientas de despliegue de App

  • Vercel - Despliegue rápido para aplicaciones web y frontend.
  • Netlify - Plataforma para hosting y despliegue de sitios web JAMstack.
  • Firebase Hosting - Despliegue para aplicaciones web con backend Firebase.
  • GitHub Actions - CI/CD para automatizar despliegues.
  • Fastlane - Automatización para despliegue en tiendas móviles.

Plataformas

  1. Android: AAB/APK firmados, Play Console.
  2. iOS: Build firmado, App Store Connect.
  3. PWA: Manifest + Service Worker.
