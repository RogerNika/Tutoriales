Opciones de almacenamiento

Las aplicaciones móviles pueden guardar información localmente usando bases de datos embebidas, archivos o almacenamiento clave‑valor.

Cuando se requiere sincronizar datos entre dispositivos, se combinan estas opciones locales con APIs REST, servicios en la nube o bases de datos en tiempo real.

  • Room (SQLite) en Android
  • Cloud Firestore
  • IndexedDB en aplicaciones web
  • Core Data en iOS
